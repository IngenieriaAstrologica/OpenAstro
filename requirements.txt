# Python 3 dependencies for OpenAstro.
# Install with:  pip install -r requirements.txt
#
# Time zones use the standard-library "zoneinfo" module (Python 3.9+), which
# reads the operating system's time-zone database (/usr/share/zoneinfo on
# Linux) -- no third-party package needed. On a platform without a system
# database (e.g. native Windows) install the data package:  pip install tzdata
#
# The GTK 3 GUI stack (PyGObject + pycairo + the GObject-introspection
# typelibs for GTK 3 and librsvg) is best installed from system packages,
# not from pip. On Debian/Ubuntu:
#     sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-rsvg-2.0
#
# Optional: raster export (Save as PNG/JPG) shells out to ImageMagick's
# "convert" command:
#     sudo apt install imagemagick
#
# See README.md for the full setup.
